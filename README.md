# HadoVie – bản cập nhật

Kho này chỉ chứa các bản cập nhật của phần mềm bán hàng HadoVie (HADO STORE).
Không có dữ liệu bán hàng hay mã nguồn ở đây.

- `latest.json`: thông tin bản mới nhất (số phiên bản, đường dẫn file, mã kiểm tra sha256).
- `HadoVie-capnhat-<phiên bản>.hvu`: file cập nhật.

HadoVie trên máy chủ cửa hàng (từ bản 2026.11.01.3) tự kiểm tra `latest.json` mỗi giờ và tự cài bản mới
khi cửa hàng rảnh (10 phút không có đơn, hoặc 22:00–06:00). Có thể tắt trong **Cài đặt → Cập nhật phần mềm**
và bấm **Cập nhật ngay** bằng tay.
